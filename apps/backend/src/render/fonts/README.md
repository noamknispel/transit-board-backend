# Fonts

`ter-u12n-ascii.bdf` is the printable-ASCII subset (U+0020–U+007E, plus the
replacement glyph) of **Terminus Font 12px** (`ter-u12n.bdf`), the same font
CircuitPython uses for `terminalio.FONT`. Using it server-side keeps rendered
text identical to what the firmware used to draw itself.
